# Command & Control

The **Command & Control** module provides "Business-led AI oversight," allowing leaders to steer AI behavior without touching code.

## Observability

Watch your Machineforce working in real-time.

*   **Live Activity Feeds**: See what agents are processing right now.
*   **Sentiment Analysis**: Monitor the tone and "mood" of agent interactions.
*   **Drift Detection**: Get alerts when agents start deviating from established patterns.

## Intervention (Steering)

When an agent needs correction, you don't need to retrain the model. You simply **steer** it.

*   **Context Injection**: Update the "Context" layer to provide new information or constraints.
*   **Override**: Manually intervene in a critical workflow.
*   **Behavioral Toggles**: Adjust parameters like "Creativity," "Caution," or "Empathy" on the fly.
